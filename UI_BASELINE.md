# Baseline Visual

La baseline actual es deliberadamente mínima y no debe romperse durante autenticación:

- Fondo oscuro `#0f172a`.
- Texto principal claro y acento cyan `#22d3ee`.
- Layout centrado con ancho máximo aproximado de `1024px`.
- Tipografía sans-serif del sistema.
- Botones redondeados; primario cyan con texto oscuro y secundario con borde slate.
- La home debe seguir mostrando el nombre Streamish o el nombre del tenant resuelto.

Los cambios de autenticación deben conservar esta jerarquía, espaciado y contraste. El diseño completo de la tienda queda para la Sesión 4.
